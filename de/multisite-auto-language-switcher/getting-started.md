# Erste Schritte

Nach der Installation des Plugins bist du im Grunde fertig. Multisite Auto Language Switcher verwendet die bevorzugte(n) Sprache(n) des Benutzers, die automatisch vom Browser an deine Website gesendet werden, und erkennt, ob der aktuelle Inhalt in einer Sprache verfügbar ist, die vom Benutzer bevorzugt wird. Das Plugin funktioniert nur, wenn du Multisite Language Switcher bereits eingerichtet und Inhalte für mindestens zwei Sprachen verbunden hast.

## Weiterleitungen pro Benutzer deaktivieren

Als Benutzer hast du in deinem Profil unter **Automatische Weiterleitung** eine Einstellung, mit der du die automatische Weiterleitung für deinen Benutzer deaktivieren kannst. Aktiviere dazu das Kontrollkästchen „Automatische Weiterleitung zur bevorzugten Sprache deaktivieren“ und du wirst nicht mehr automatisch weitergeleitet.
