# Multisite Auto Language Switcher

Multisite Auto Language Switcher ist eine praktische Erweiterung für [Multisite Language Switcher](https://de.wordpress.org/plugins/multisite-language-switcher/), die eine automatische Weiterleitung zur bevorzugten Sprache eines Benutzers hinzufügt. Dazu verwendet er die bevorzugte Sprache, die der Benutzer in seinem Browser definiert hat und die bei jeder Anfrage automatisch übermittelt wird, um eine passende Sprache innerhalb deiner Website zu ermitteln. Wenn eine Übereinstimmung gefunden wird, leitet es den Benutzer automatisch zu dieser Variante des Inhalts weiter.
