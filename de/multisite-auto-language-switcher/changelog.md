# Änderungsprotokoll

## Version 1.1.3 <Badge type="info" text="12. August 2026" />

* Hinzugefügt: Hinweis für Screenreader, dass Dokumentationslinks in einem neuen Tab geöffnet werden
* Behoben: Fehlendes aria-current-Attribut für die aktuelle Sprache im Sprachwechsler
* Behoben: Links im Sprachwechsler enthalten nun kein redundantes title-Attribut mehr
* Behoben: Maskieren der Linkausgabe im Sprachwechsler

## Version 1.1.2 <Badge type="info" text="25. Mai 2026" />

* Hinzugefügt: Kompatibilität mit WordPress 7.0

## Version 1.1.1 <Badge type="info" text="14. Dezember 2025" />

* Aktualisiert: Kompatibilität mit den neuesten Versionen von Multisite Language Switcher

## Version 1.1.0 <Badge type="info" text="13. Mai 2025" />

* Hinzugefügt: Benutzeroption zur Deaktivierung der Weiterleitung über die Profileinstellungen
* Hinzugefügt: Der Umleitungsparameter wird jetzt nach der Weiterleitung via JavaScript entfernt

## Version 1.0.1 <Badge type="info" text="2. Dezember 2024" />

* Behoben: Unerwünschte Weiterleitungen für bestimmte Seiten
* Behoben: Erneute Weiterleitung nach explizitem Klick auf eine Sprache im Sprachwechsler
