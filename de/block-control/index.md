# Block Control

Mit Block Control kannst du im Block-Editor Bedingungen für Blöcke festlegen, um sie basierend auf diesen Bedingungen auszublenden. Es ist mit jedem Block kompatibel, nicht nur mit denen von WordPress selbst, sondern auch mit individuellen Blöcken aus Plugins.
